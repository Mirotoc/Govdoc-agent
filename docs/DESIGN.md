# 디자인 원칙

이 저장소의 그래픽과 문서 형식은 두 가지 기준을 따라요.

- **보이는 것**: [KRDS 대한민국 정부 디자인 시스템](https://www.krds.go.kr)
- **읽히는 것**: [토스 UX 라이팅 8원칙](https://toss.tech/article/8-writing-principles-of-toss)

공공 문서를 다루는 도구라서 시각적으로는 정부 서비스와 같은 기준을 쓰고, 글은 누구나 쉽게 읽을 수 있게 써요.

<br>

## 1. 색상 · KRDS 토큰

KRDS 공식 토큰 파일(`krds_tokens.css`)의 값을 그대로 써요. 강조 색은 파란색 하나만 써요.

| 역할 | 토큰 | 값 | 쓰는 곳 |
|---|---|---|---|
| 강조 | primary-50 | `#256ef4` | 배지, 자물쇠 아이콘, 다이어그램 테두리 |
| 강조 배경 | primary-5 | `#ecf2fe` | 배너 배경, 다이어그램 노드 |
| 강조 테두리 | primary-20 | `#b1cefb` | 문서 아이콘 테두리 |
| 제목 | gray-90 | `#1e2124` | 큰 제목 |
| 본문 | gray-70 | `#464c53` | 부제목 |
| 보조 | gray-50 | `#6d7882` | 설명, 연결선 |
| 구분선 | gray-20 | `#cdd1d5` | 문서 아이콘 줄 |
| 위험 | danger-50 | `#de3412` | 오류 표시 |
| 위험 배경 | danger-5 | `#fdefec` | 오류 강조 배경 |

오류 심각도도 KRDS 시스템 색상과 맞췄어요.

| 심각도 | 색 | 토큰 |
|---|---|---|
| critical, high | 빨강 | danger-50 `#de3412` |
| medium | 노랑 | warning-50 `#9e6a00` |
| low | 파랑 | information-50 `#0b78cb` |

<br>

## 2. 서체 · KRDS 타이포그래피

- 서체: **Pretendard GOV**를 쓰고, 없으면 Pretendard, 맑은 고딕 순서로 대체해요.
- 크기: 배너 제목 60px(Display large), 부제목 24px(Heading medium), 설명 17px(Body medium)
- 행간: KRDS 기준대로 150% 이상을 유지해요.

<br>

## 3. 글쓰기 · 토스 라이팅 8원칙

| 원칙 | 이 저장소에서 지킨 방법 | 예시 |
|---|---|---|
| 다음을 예측할 수 있게 | 실행 단계마다 무엇이 나오는지 먼저 알려 줘요 | "규칙 검사만 해 봐요 (AI 없이도 돼요)" |
| 잡초 뽑기 | 뜻을 바꾸지 않는 단어는 지워요 | ~~본 프로그램은 ~를 수행합니다~~ → "~해요" |
| 빈 문장 지우기 | 자리를 채우려고 넣은 문장은 쓰지 않아요 | |
| 핵심에 집중 | 표 한 줄에 정보 하나만 담아요 | 코드 둘러보기 표 |
| 말하듯 쉽게 | 전문 용어는 풀어서 써요 | "로컬 LLM" → "내 PC에 설치한 작은 언어모델" |
| 강요 대신 제안 | 프로그램은 판단을 강요하지 않아요 | "최종 판단은 담당자가 해 주세요" |
| 누구나 아는 말 | 은어나 줄임말을 쓰지 않아요 | |
| 감정 헤아리기 | 오류를 알릴 때 탓하지 않고 할 일을 알려 줘요 | "Ollama가 켜져 있는지 확인해 주세요" |

문장은 모두 **해요체**로 맞췄어요. 프로그램 출력 메시지도 같은 원칙을 따라요.
